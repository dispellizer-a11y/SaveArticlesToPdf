# SaveArticlesToPdf

엑셀에 정리된 기사(보도자료) 링크 목록을 읽어서, 각 기사 페이지에 있는
**"인쇄" 버튼을 클릭해 인쇄용 레이아웃으로 전환한 뒤** 그 화면을 PDF 파일로
저장하는 스크립트입니다.

엑셀 형식은 아래와 같은 열 구성을 가정합니다 (시트별로 연도 구분, 헤더가
3번째 행에 있는 형태):

| NO | 게시일 | 언론사 | 제목 | 주소 | 비고 |
|----|--------|--------|------|------|------|

## 동작 방식

1. Playwright로 실제(무헤드) Chromium을 띄워 기사 URL에 접속합니다.
2. 페이지에서 "인쇄"/"프린트"/"print" 텍스트, class, id, onclick, alt,
   aria-label 등을 폭넓게 검사해서 인쇄 버튼을 찾습니다.
3. 버튼을 클릭합니다.
   - 클릭 시 별도의 인쇄용 페이지가 새 탭으로 열리는 사이트는 그 새 탭을
     대상으로 저장합니다.
   - 같은 페이지에서 `window.print()`만 호출하는 사이트는(실제 OS 인쇄
     대화상자는 자동화 환경에서 열 수 없으므로) 인쇄 미디어(`@media print`)
     스타일을 강제 적용해 같은 결과를 재현합니다.
4. 최종 화면을 `page.pdf()`로 저장합니다.
5. 만약 어떤 방식으로도 인쇄 버튼을 찾지 못하면, 원문 페이지에 인쇄
   스타일만 적용해 저장하고(`fallback_no_button`으로 로그에 표시) 다음
   기사로 넘어갑니다. 이 경우는 "바로 저장"에 가까우므로 결과 CSV에서 꼭
   확인해 주세요.

사이트마다 마크업이 전부 달라서 100% 성공을 보장하지는 못합니다. 특정
언론사 사이트에서 계속 실패하면, 실패한 URL과 함께 알려주시면 해당
사이트 전용 규칙을 추가해 드릴 수 있습니다.

## 설치 (최초 1회)

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows는 .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

## 사용법

엑셀 파일을 프로젝트 폴더 아무 곳에나 두고 경로를 지정합니다.

```bash
# 1) 먼저 소규모로 테스트 (5건만, 브라우저 창을 보면서 확인)
python save_articles_to_pdf.py --excel 보도자료.xlsx --limit 5 --headed

# 2) 특정 연도(시트)만 처리
python save_articles_to_pdf.py --excel 보도자료.xlsx --sheets 2025,2026

# 3) 전체 처리 (기본: 헤드리스로 조용히 실행)
python save_articles_to_pdf.py --excel 보도자료.xlsx
```

- PDF는 `output/<시트명>/<번호>_<게시일>_<언론사>_<제목>.pdf` 형태로 저장됩니다.
- 처리 결과는 `output/results.csv` 에 한 줄씩 누적 기록됩니다
  (`status`: success / fallback_no_button / failed).
- 이미 저장된 파일은 기본적으로 건너뜁니다. 중간에 멈춰도 다시 실행하면
  이어서 진행됩니다. (`--overwrite` 옵션으로 강제 재저장 가능)

### 주요 옵션

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--excel` | 엑셀 파일 경로 (필수) | - |
| `--output` | PDF 저장 폴더 | `output` |
| `--sheets` | 처리할 시트명 (콤마 구분) | 전체 시트 |
| `--limit` | 테스트용 최대 처리 건수 | 0(전체) |
| `--delay` | 기사 간 대기 시간(초), 너무 빠르면 차단될 수 있음 | 1.5 |
| `--headed` | 브라우저 창을 보이게 실행 | 꺼짐(headless) |
| `--overwrite` | 기존 PDF 덮어쓰기 | 꺼짐 |

## 주의사항

- 2020~2022년처럼 오래된 기사는 언론사가 페이지를 삭제했거나 URL이 바뀌어
  접속이 안 될 수 있습니다. 이런 경우 `results.csv`에 `failed`로 기록되니,
  실제 총 처리 건수(535건)와 성공 건수를 비교해서 확인해 주세요.
- 총 500건 이상을 한 번에 돌리면 시간이 꽤 걸립니다(건당 대기시간 포함
  약 몇 초~10여 초). 먼저 `--limit`으로 소량 테스트 후 전체 실행을
  권장합니다.
- 일부 사이트는 팝업(광고/쿠키 동의창)이 인쇄 버튼을 가릴 수 있습니다.
  이런 사이트가 있으면 알려주세요, 팝업 닫기 로직을 추가해 드립니다.
